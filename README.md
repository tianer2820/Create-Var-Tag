# Create: Var Tag

A quality of life addon for the [Create Mod](https://modrinth.com/mod/create) that replaces the headache of item-based Redstone Link frequencies with named string variables!

## The Problem

The original Create mod introduces the Redstone Link, a fantastic tool for wireless redstone. It's especially powerful when combined with mods like Valkyrien Skies or Aeronautics, where wireless redstone is essential for controlling complex moving mechanisms. 

However, standard Redstone Links use items (like an Apple or Cobblestone) to define their frequency. While simple, this becomes incredibly difficult to manage in large control systems. Remembering which item corresponds to which function is hard, meaningless item assignment is confusing, and accidentally causing frequency collisions is a constant headache.

## The Solution: Var Tags

This addon introduces the **Var Tag**, an item that allows you to set Redstone Link frequencies using custom text names! No more item frequency collisions.

### Features
*   **Simple Crafting:** Craft a Var Tag using **1 Iron Nugget** and **1 Iron Sheet**.
*   **Custom Variable Names:** Right-click with the Var Tag in your hand to open a custom UI where you can type any string name for your variable.
*   **Nearby Network Detection:** The UI conveniently displays a list of variable names currently set on nearby Redstone Links, making it easy to see what frequencies are already in use.
*   **Easy Assignment:** Once you've set a name on your Var Tag, simply right-click a Redstone Link with it to assign the frequency. Only Redstone Links with the exact same variable name tag will match and connect.

## Compatibility

Currently supports:
*   **Minecraft:** `1.21.1`
*   **Create Mod:** `6.0.10`
